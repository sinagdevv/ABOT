## What this does and does not prove

Proves: the full Noir lifecycle used by ABOT's agent — register → fund →
policy-check → authorize → claim — works against the real, currently-deployed
Testnet contracts, with real confirmed transaction hashes. The run used the
same SDK call shapes as `packages/agent/src/noir-service.ts`, but the evidence
was generated by the standalone `docs/scripts/testnet-smoke.mjs` process with
throwaway keys, not by the deployed ABOT application.

Does not prove: a deployed ABOT Noir payout, Supabase runtime access, or the Velo
checkout leg. The deployed Velo webhook endpoint rejected both a synthetic
payload with a fake signature and one with no signature with HTTP 400 on
2026-11-07; this proves the fail-closed signature boundary, not a real signed
delivery or settlement. Velo's positive signature verification is also covered
by unit tests against the SDK's own `Velo.webhooks.verify`.

Reproduce with `node docs/scripts/testnet-smoke.mjs` (same script, kept here for anyone who
wants to re-run it against fresh Friendbot-funded keys).
